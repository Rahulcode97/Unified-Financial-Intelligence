Research Platform · Built in Rust

10 idle PCs, one self-driving fleet.

The office had retired PCs sitting switched off. I wrote a desktop agent in Rust that turns each one into a worker. It runs collection browsers, reports its own health, picks up work, recovers from stalls and updates itself. The team runs the whole fleet from a web page, or by just asking for what they want.

Lifecycle

From a dusty PC to a fleet worker.

🔑

Pair

An admin issues a short-lived PIN. The agent presents it once and receives its own revocable device key.

💓

Heartbeat

Every beat reports free memory, CPU, disk, slot capacity and what each slot is doing.

🧭

Schedule

The reply tells each slot which job to run, favouring the job with the most hours left.

🩹

Self-heal

A slot with no progress gets restarted. After two restarts, its work moves to another machine.

🚀

Self-update

Tagging a release builds a zip in CI. Every machine downloads it and updates itself.

Under the hood

Small agent, serious engineering.

RUST · TOKIO · AXUM

A tray app that runs itself

An async Rust agent sits in the system tray. Its own window is a local page protected by a token minted at launch.

REAL BROWSERS

Full-speed browsers, out of the way

The agent launches real (not headless) browser windows with the collection extensions, then parks them off-screen so they keep running at full speed. A window pops back only when a site needs a human.

LOCAL OUTBOX

Never loses a row

Collected rows land in a local database first and upload when the network allows, so a dropped connection costs nothing.

FAIR SCHEDULING

Placement that doesn't starve

Every job with work gets at least one browser, the job with the most hours left gets more, and browsers don't hop between jobs. Time-left estimates come from measured throughput.

HOT UPDATES

Ships itself

The agent updates from tagged releases. The browser extensions update from the portal build within minutes, and each machine restarts its browsers on the new code.

NETWORK & SCHEDULES

Plays nice with the office

Built-in VPN exits adapt when another VPN is detected. Quiet hours pause a machine or run fewer browsers on a schedule, and slot caps are set per machine.

Plain-English control, safely

A copilot that can't break things.

The copilot uses the same tools as the fleet page, exposed over the Model Context Protocol. The limits live in code, not in a prompt.
